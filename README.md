# AI Revenue Agent

سیستم اولیه برای پیدا کردن فرصت‌های درآمدی در کسب‌وکارها.

## کاری که انجام می‌دهد

یک سایت کسب‌وکار را دریافت می‌کند.

اطلاعات سایت را استخراج می‌کند.

آن را به مدل هوش مصنوعی می‌دهد.

مشکلات و فرصت‌های قابل‌حل را شناسایی می‌کند.

خدمات قابل فروش پیشنهاد می‌دهد.

یک متن اولیه برای ارتباط با مشتری تولید می‌کند.
